# Assignment Deadline Planner

A simple website made to manage and track student assignments and deadlines. This project was made for my course CSE326 using HTML and CSS.

## Purpose

Students often struggle to keep track of multiple homework assignments and project deadlines. This website gives a simple way to submit new assignments, organize schedules, and view upcoming coursework details.

## Tools Used

* HTML
* CSS
* Netlify (for hosting the website)

## Project Files

* index.html : Home page and dashboard of the website
* style.css : Styling for all the pages

## How to Run

1. Download or clone this repository.
2. Open index.html in any web browser.

## Live Website

https://stellular-sopapillas-f12117.netlify.app

## How I Built It

I planned the pages first, then wrote the structure in HTML and the design in CSS. I kept the design clean and simple so that it is easy to read on any screen.

A working web application that is live online through Netlify.
